# GonzalezSusatama

Invitacion digital de boda en React + Vite.

## Ejecutar

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Estructura recomendada

- `src/components/sections/`: secciones de la pagina
- `src/config/siteContent.js`: textos y datos editables
- `src/assets/photos/cover/`: foto de portada
- `src/assets/photos/gallery/`: galeria de ustedes
- `src/assets/photos/README.md`: guia rapida de fotos
