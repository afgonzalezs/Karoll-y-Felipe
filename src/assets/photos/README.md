# Fotos del proyecto

Sube tus imagenes aqui para personalizar la web sin tocar codigo.

## Portada principal

- Carpeta: `src/assets/photos/cover/`
- Deja 1 foto (o varias). Se usa la primera en orden alfabetico.

## Galeria de ustedes

- Carpeta: `src/assets/photos/gallery/`
- Sube todas las fotos que quieras en `.jpg`, `.jpeg`, `.png` o `.webp`.

## Recomendaciones

- Formato ideal: `.webp` o `.jpg`
- Peso recomendado: menos de 1 MB por foto
- Nombre ejemplo: `01-portada.jpg`, `02-momento.webp`
